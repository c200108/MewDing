一、我们如何收集和使用你的个人信息及申请的权限

（一）你主动提供的信息

以下信息都由你在使用对应功能时主动填写或添加，都可以不填；全部只保存在本机，不会上传。

  1. 个人资料：昵称、性别、生日、体重、起床和睡觉时间、三餐时间。用于称呼你、决定是否显示经期功能、计算每日喝水目标、安排提醒时间。
  2. 健康记录：喝水、吃饭、睡觉记录；经期日期（属于敏感个人信息，只有你主动标记才会产生）。用于统计、提醒和经期预测。经期预测仅供参考，不构成医疗建议。
  3. 便签内容：文字、图片、录音、视频。用于便签显示和便签提醒。图片和视频通过系统「照片选择器」由你逐个挑选，萌叮不需要、也不申请存储或相册权限，看不到相册里的其他内容。
  4. 提醒与宠物数据：自定义提醒（吃药、久坐等）及完成记录、「关心 TA」里你填写的称呼和提醒时间、宠物、萌点、成就、小游戏成绩、各项设置。用于软件基本功能。

我们不收集：手机号、身份证号、通讯录、短信、通话记录、精确位置、设备标识符（IMEI、Android ID、OAID、MAC 地址等）、已安装应用列表、剪贴板内容。萌叮没有接入任何统计、广告、推送或崩溃上报 SDK。

（二）申请的系统权限

所有需要弹窗授权的权限，都在你第一次用到对应功能时才申请；你拒绝后不影响其他功能，也可以随时在手机「设置 → 应用 → 萌叮 → 权限」中关闭。在你同意本政策之前，萌叮不会申请任何权限。

  1. 通知（POST_NOTIFICATIONS）：发送喝水、吃饭、睡觉、经期、自定义提醒，显示通知栏常驻宠物。完成新手引导或打开提醒时申请。
  2. 精确闹钟（SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM）：让提醒在你设定的时间准时响起。安装即有；Android 12～13 上可在系统设置中关闭，关闭后提醒可能延迟。
  3. 悬浮窗 / 显示在其他应用上层（SYSTEM_ALERT_WINDOW）：桌面悬浮宠物。只在你打开「桌面悬浮宠物」时引导你去系统设置开启。
  4. 身体活动识别（ACTIVITY_RECOGNITION）：「陪我走路」通过手机计步传感器统计步数，只计数，不记录位置和轨迹。打开该功能时申请。
  5. 大致位置（ACCESS_COARSE_LOCATION）：仅用于「本地天气」。坐标只保留两位小数（约 1 公里精度），发送给 Open-Meteo 天气服务查询天气，萌叮不保存坐标。不申请精确位置，也不在后台获取位置。打开「本地天气」时申请。
  6. 麦克风（RECORD_AUDIO）：便签录音。第一次在便签里录音时申请，录音只保存在本机。
  7. 安装未知应用（REQUEST_INSTALL_PACKAGES）：在「关于萌叮 → 检查更新」下载新版后发起安装，系统还会再让你确认一次。只在你点「下载并更新」时引导开启。
  8. 前台服务（FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE）：让通知栏宠物、桌面悬浮宠物、计步在后台持续运行。只在你打开这些开关后运行，全部关闭即停止。
  9. 开机自启（RECEIVE_BOOT_COMPLETED）：手机重启、萌叮升级、修改时间或时区后，重新排好提醒并恢复你打开的常驻宠物，避免漏提醒。萌叮不会被其他应用关联启动，也不会关联启动其他应用。在你同意本政策之前不会自启。
  10. 忽略电池优化（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）：防止系统省电把提醒和常驻宠物杀掉。在「权限与提醒保障」页由你选择是否开启。
  11. 生物识别（USE_BIOMETRIC）：「隐私锁」解锁。验证由手机系统完成，萌叮拿不到你的指纹、面容或密码。
  12. 网络（INTERNET）、网络状态（ACCESS_NETWORK_STATE）：仅用于本地天气、检查和下载更新、下载显示字体，均由你主动触发。萌叮的基本功能完全离线可用。
  13. 振动（VIBRATE）、唤醒锁（WAKE_LOCK）：提醒时振动，锁屏时也能按时提醒。安装即有，不涉及个人信息。

（三）依法无需征得同意的情形

根据相关法律法规，以下情形中处理个人信息无需征得你的同意：为订立、履行你作为一方当事人的合同所必需；为履行法定职责或者法定义务所必需；为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需；为公共利益实施新闻报道、舆论监督等行为，在合理范围内处理个人信息；在合理范围内处理你自行公开或者其他已经合法公开的个人信息；法律、行政法规规定的其他情形。由于萌叮不把你的信息传出本机，实际上我们不会接触到你的个人信息。

二、我们如何使用 Cookie 和同类技术

萌叮不使用 Cookie、网络信标、像素标签、设备指纹或任何同类追踪技术，也不会为你建立用户画像或进行个性化推荐。

三、我们如何存储你的个人信息

  1. 存储地点：你的信息全部保存在你手机上萌叮的私有目录中（中华人民共和国境内的设备由你自己持有），其他应用无法读取。萌叮没有服务器，云端不保存你的任何数据。
  2. 存储期限：直到你自己删除、注销账号或卸载萌叮为止。注销账号或卸载后，本机数据会被全部删除，无法恢复。
  3. 「导出备份」生成的备份文件由你自己保存到你选择的位置，用你设置的密码加密，我们无法获取。
  4. 如以后上线「云同步」，会在开启前单独列明上传哪些内容并征得你的同意，并相应更新本政策。

四、我们如何共享、转让、公开披露你的个人信息

  1. 共享：我们不会与任何公司、组织或个人共享你的个人信息。唯一的对外联网请求见第十三节所列的第三方服务（天气、更新、字体下载），这些请求只发送完成该功能必需的内容，不包含你的记录。
  2. 转让：我们不会转让你的个人信息。
  3. 公开披露：我们不会公开披露你的个人信息。
  4. 你主动使用「分享便签」「导出备份」时，文件由你选择发送对象，接收方如何处理由你和接收方决定。

五、我们如何保护你的个人信息

  1. 健康记录、经期、便签文字使用手机系统密钥库（Android Keystore）中的密钥以 AES-GCM 加密保存，密钥无法从手机中导出。
  2. 所有数据存放在应用私有目录，并关闭了系统自动备份（allowBackup=false），不会被系统备份到云端。
  3. 「隐私锁」可让打开萌叮需要验证指纹、面容或锁屏密码；「通知伪装」可让经期相关提醒在锁屏上不显示敏感字样。
  4. 联网请求均使用 HTTPS 加密传输。
  5. 请妥善保管你的手机和备份密码。如果手机丢失或被他人使用，他人可能看到你的记录，建议打开「隐私锁」。

六、你的权利

  1. 查看和更正：个人资料在「我的 → 个人信息」，各项记录在对应页面，都可以随时查看和修改。
  2. 导出：「我的 → 隐私与数据 → 导出备份」可导出一份用你的密码加密的完整备份。
  3. 删除：各条记录、便签、提醒都可以单独删除；关闭某项功能后不再产生对应记录。
  4. 撤回授权：可随时在手机「设置 → 应用 → 萌叮 → 权限」中关闭任何权限；撤回后不影响撤回前基于授权已进行的处理。
  5. 注销账号：在「我的 → 注销账号」（或「我的 → 隐私与数据 → 注销账号」）中查看将被删除的内容，二次确认后，萌叮会立即停止所有提醒、通知栏宠物和悬浮宠物，删除本机全部数据（宠物、萌点、便签及图片视频录音、经期等健康记录、提醒和已排好的闹钟、个人资料、全部设置、已下载字体、缓存、加密密钥），并回到首次启动状态。云端没有你的数据，无需另外申请删除。注销后数据无法恢复。
  6. 投诉与反馈：如对个人信息处理有疑问、意见或投诉，可通过第十二节的方式联系我们，我们会在 15 个工作日内答复。

七、我们如何处理未成年人的个人信息

萌叮主要面向成年人。未满 14 周岁的儿童，请在父母或其他监护人的陪同下阅读本政策，并在监护人同意和指导下使用。萌叮不会主动识别或收集儿童信息；监护人可随时通过「注销账号」删除孩子的全部数据，或通过第十二节联系我们。

八、本政策的修订和通知

我们可能随版本更新修订本政策，页首会显示新的更新日期，历史版本见第十一节。发生重大变更时（例如新增收集的信息类型、新增第三方服务、上线云同步、开发主体变更），你下次打开萌叮会看到弹窗提示，需要你重新同意后才能继续使用；不同意的，萌叮将停止提醒和常驻服务并退出。

九、本政策的适用范围

本政策适用于萌叮提供的全部功能。萌叮中可能出现的外部链接（如第三方服务官网），由该第三方按其自己的隐私政策处理，不适用本政策，请你查看对方的隐私政策。

十、其他

  1. 个人信息：以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
  2. 敏感个人信息：一旦泄露或者被非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，本应用中指经期等健康记录。
  3. 本机 / 本地存储：数据只保存在你的手机存储中，不经过任何服务器。
  4. 第三方 SDK：由第三方提供、集成在本应用中实现特定功能的软件工具包。
  5. 本政策的解释及争议解决适用中华人民共和国法律。
